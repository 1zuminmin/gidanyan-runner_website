# EXランキング（まずローカルで確認）

## 起動

Node.js 24以降を用意し、webリポジトリのフォルダで次を実行します。追加パッケージは不要です。

```
node server/server.mjs
```

- ホーム： http://127.0.0.1:8787/
- ランキング： http://127.0.0.1:8787/game/ranking.html
- EX： http://127.0.0.1:8787/game/stage4.html
- 終了：ターミナルでCtrl+C

SQLiteは `server/data/ranking.sqlite` に保存します。Gitには入れません。個人トークンはブラウザのlocalStorage、サーバーにはトークンのSHA-256のみ保存します。ニックネームは公開情報です。Cookieやパスワードの登録は不要ですが、端末変更・シークレットモード・閲覧データ削除では別人扱いになります。

## Unityとの接続

Unity側のRunnerWebBootstrap / RunnerWebBridge.jslib / RunnerGameManager / WebGLテンプレートlaunch.jsに追加した送信処理を含めて再ビルドし、ビルド4ファイルをweb側に差し替えてください。古いビルドは漫画用の終了通知だけ送るため、ランキング登録フォームが開きません。

今回の計算規則 `ex-v1` は `floor(走行距離) + キャンディ数 × 3750` です。ゲームの採点規則を変える場合はサーバー検証・クライアント検証とrulesetを一緒に更新し、別のDBでシーズンを分けてください。

## ローカルの表示例

```
ENABLE_DEMO=1 DB_PATH=/tmp/gidanyan-ranking-demo.sqlite node server/server.mjs
```

http://127.0.0.1:8787/ranking-preview.html を開きます。「テストプレイを開始」→「テストのリザルトを表示」→ニックネーム登録で実際のAPI・DBを試せます。テストの数値であることを明記しており、実際のゲームのスコアではありません。デモDBは本番で再利用しないでください。ENABLE_DEMOを指定しなければ、この表示例はサーバーから配信しません。

## 公開する際に必要な設定（未実施）

現在のGitHub Pagesは静的サイトなので、このNodeサーバーは動きません。公開先が決まったら別のNode.js 24対応サーバーと永続ディスクを用意します。

- `HOST=0.0.0.0`、`PORT`：公開先に合わせる
- `DB_PATH`：永続ディスク上のDBパス。SQLiteは単一サーバープロセスで運用
- `ALLOWED_ORIGINS=https://game.gidaisai.jp`：許可するサイトだけをカンマ区切りで設定
- `game/ranking-config.json` の `apiBase` をHTTPSのAPIのURLにする
- HTTPS終端、バックアップ、監視、レート制限を公開先で設定
- DBには個人識別子のハッシュとニックネームが含まれるため、公開ディレクトリに置かない
- DBの書き込み中のコピーは避け、停止時にSQLite関連ファイル一式をバックアップ
- 不適切なニックネームの非表示・削除などの管理運用を決める

apiBase未設定の公開サイトには「公開準備中」と表示され、ブラウザの自己ベストだけ保存します。Gitにpushするだけでは共有ランキングは公開されません。

## 検証・制約

`node --test tests/*.test.mjs` で確認できます。

- 開始時にサーバーが発行したrunIdを使い、送信元サイト、匿名トークン、形式、採点式、値の範囲、経過時間、再送を確認
- 同じ記録の再送は重複しない。1ブラウザにつき自己ベスト1件、同点は同順位（1,1,3方式）
- ニックネームはtextContentで表示し、SQLはパラメータ化
- IP単位120リクエスト/分（プロセス内）。リバースプロキシ経由の本番ではプロキシ側でも適切に制限する
- Unity/WebGLの値はクライアントから届きます。改ざんを完全に防ぐものではなく、景品や厳密な競技用途にはサーバー側でのプレイ検証が別途必要です
- サーバー未接続のプレイは後からランキングへ送信できません。ローカル自己ベストは残ります
- サーバーへの登録に成功しても自己ベスト未満の記録は順位を変更しません

実装にはNode.js標準のSQLite APIを使用：https://nodejs.org/docs/latest-v24.x/api/sqlite.html
